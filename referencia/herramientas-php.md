No hace falta instalar nada para empezar, pero tarde o temprano vas a querer un entorno de verdad.

## Para probar algo rápido: 3v4l.org

[3v4l.org](https://3v4l.org) ejecuta código PHP en el navegador, en muchas versiones a la vez, sin cuenta ni instalación.

- No hay `input()`: los datos van escritos en el código.
- **Todo lo que pegues queda público.** Nada de datos reales, contraseñas ni cosas de una empresa.

En este sitio, además, los ejemplos que empiezan con `<?php` se pueden ejecutar directamente en la página.

## Para trabajar en serio

- **[Laravel Herd](https://herd.laravel.com)** instala PHP y lo deja listo para usar en Windows y macOS, sin pelear con configuraciones.
- **[PhpStorm](https://www.jetbrains.com/phpstorm/)** es un editor pensado para PHP: autocompleta, avisa errores antes de ejecutar y trae un depurador. Si eres estudiante, puedes pedir una [licencia educativa gratuita](https://www.jetbrains.com/community/education/#students).

Si algo falla al instalar, guarda el mensaje de error completo. Sin el mensaje, nadie te puede ayudar.

## Para guardar y compartir código: GitHub

Crea una cuenta en [GitHub](https://github.com). Ahí vas a guardar tus proyectos y trabajar en equipo con control de versiones, así que mejor tenerla lista desde el principio.

## El manual

El [manual de PHP en español](https://www.php.net/manual/es/) tiene una página para cada función, con ejemplos. Un truco: escribe `php.net/` seguido del nombre de la función (por ejemplo, [php.net/array_pop](https://www.php.net/array_pop)) y te lleva directo.
